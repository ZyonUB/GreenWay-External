# GreenWay External

GreenWay is a native macOS desktop companion with a green-themed SwiftUI interface.

## Install

On macOS 13 or later, with Xcode Command Line Tools installed, run:

```bash
curl -fsSL "https://raw.githubusercontent.com/ZyonUB/GreenWay-External/main/install.sh" | bash
```

If Swift is not installed, run `xcode-select --install` first.

## Features

- Dashboard with app status and quick navigation
- Visuals page with local preview toggles
- Settings page with companion-app preferences
- Native macOS SwiftUI interface

This project is a standalone desktop companion. It does not inject into Roblox, modify game processes, or provide cheats for other people's experiences.
